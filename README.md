 
## Overview

This repository provides the necessary data and code required to replicate the analyses and results presented in the paper titled "Land-Clearing Deregulation Increased Burning and Forest Loss on Public and Indigenous Lands".

- All main tables (Tables 1-4) and figures (Figures 1-2)
- All supplementary tables (SI Tables S1-S9) and figures (SI Figures S1-S2, S4-S10)

**Not included:** SI Figure S3 (fire ignition maps by tenure, 2015-2022). This figure requires ~20GB of fire detection point data processed on a n2-highmem-32 (32 vCPU / 256 GB RAM) cloud instance and cannot be replicated on a standard workstation.

## Data

| File | Description |
|------|-------------|
| `data/grid_month_panel_2km.rds` | Main panel: ~197k 2km hexagonal grids × 96 months (2015–2022), 42 columns. Pre-filtered to lowland Bolivia (controls ≤ 1800m elevation). Includes fire counts by vegetation type, land use area, climate variables, tenure shares, and treatment indicators. |
| `data/shapefiles/grids/grid_bolivia_2km.shp` | Spatial grid: 2km hexagonal grid covering Bolivia (lowland focus) |
| `data/shapefiles/adm1/bol_admbnda_adm1_gov_2020514.shp` | Department boundaries (ADM1), Bolivia |

`data/grid_psm_weights_2km.rds` is bundled (1.2 MB). It can be regenerated by running `code/0_psm_prep.R`.

### Data sources

- **Fire detections:** VIIRS (NASA FIRMS), 2015-2022
- **Land use / deforestation:** MapBiomas Bolivia Collection 7
- **Climate:** CHIRPS (precipitation), ERA5 (temperature, wind)
- **Land tenure:** Instituto Nacional de Reforma Agraria (INRA), Bolivia
- **Protected areas:** SERNAP Bolivia

## Execution

**Set working directory to `replication_package/` before running any script.**

### Option A: Run everything

```r
setwd("/path/to/replication_package")
source("_run_all.R")
```

### Option B: Run individual scripts

Scripts must be run from the `replication_package/` directory:

```r
setwd("/path/to/replication_package")
source("code/0_psm_prep.R")   # Must run first
source("code/7_maps.R")        # Fast smoke test (~5 min)
```

### Execution order

| Script | Description |
|--------|-------------|
| `code/0_psm_prep.R` | PSM matching; generates `data/grid_psm_weights_2km.rds` |
| `code/1_shared_prep.R` | Shared setup (sourced automatically; do not run directly) |
| `code/2_twfe.R` | TWFE fire count table (SI Table, TWFE spec) |
| `code/3_drdid_main.R` | DR-DID main results (Tables 1-2, SI Table S1, SI Figs S1, S5-S6) |
| `code/4_drdid_byland.R` | DR-DID by land tenure (Tables 3-4, SI Figs S2, S4, S7-S10) |
| `code/5_drdid_bydept.R` | DR-DID by dept x tenure (SI Tables S2-S5) |
| `code/6_drdid_decree_only.R` | DR-DID decree-period only (SI Tables S6-S9) |
| `code/7_maps.R` | Fire density + deforestation maps (Figure 1) |
